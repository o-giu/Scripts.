## DevTools
<img src="https://raw.githubusercontent.com/o-giu/o-giu/9a03819194c3d8309883ecbfd52a2698322174c0/images/01.svg" width="20"/> Script colado direto na aba Console. Roda uma única vez, só naquela página aberta e some ao recarregar<br>
Abra o DevTools: F12 no seu navegador, Vá na aba Console, digite 'allow pasting' se precisar, Cole o código, dê enter<br>
<img src="https://raw.githubusercontent.com/o-giu/o-giu/9a03819194c3d8309883ecbfd52a2698322174c0/images/02.svg" width="20"/> Script pasted directly into the Console tab. It runs once, only on the currently open page, and disappears upon refresh<br>
Open DevTools (F12 in your browser), go to the Console tab, type 'allow pasting' if prompted, paste the code, and press Enter
